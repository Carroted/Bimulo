Note: you're playing an unfinished alpha game

Please note that Bimulo was never finished. The game was in super early Alpha and we decided to rewrite it completely due to web limitations.

We are currently working on that rewrite, which we call Simulo Next. You can join the Discord linked or view simulo.org for progress updates on Simulo Next.

Finally, if you are on Firefox, please use a Chromium browser for this game! Firefox was never supported and is extremely slow.
